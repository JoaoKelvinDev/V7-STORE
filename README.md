# V7 Store

Catálogo digital de moda masculina. O aplicativo e seus materiais ficam em [`v7-store/`](v7-store/).

```powershell
cd v7-store
npm install
npm run dev
```

Abra o endereço indicado pelo Vite, normalmente `http://localhost:3000`.
